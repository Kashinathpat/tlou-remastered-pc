**The Last of Us Remastered: PC port** 0.1.7

Added a direct game launcher and fixes for a water-and-pallet crash, shader-cache reliability,
and GPU memory handling.

> **No game files are included.** You need your own decrypted copy of the game and its update. This
> project is not affiliated with Sony Interactive Entertainment or Naughty Dog.

## Fixes and improvements

- **Fixed the confirmed crash while carrying a pallet on water.** Large, contiguous game-memory
  copies now use an ordered Vulkan buffer copy when they meet the safe conditions for that path.
  Other copies, including overlapping or irregular copies, keep using the original shader path.
- **Improved asynchronous shader and pipeline compilation.** A draw waits for its required
  background compilation to finish; if no usable worker result is available, it retries
  synchronously so the draw is not silently skipped. Failed pipelines are not cached as successful.
  Compilation remains asynchronous, though a first-use pause can occur while a needed pipeline is
  built.
- **Made shader-cache reads and writes more resilient.** Partial or damaged cache entries are
  skipped, cache writes are drained for up to two seconds on exit, and interrupted file writes do
  not replace the last complete cache file.
- **Reduced GPU staging-memory retention.** The Vulkan staging pool keeps a smaller 32 MiB device
  local reserve and trims unused device-local blocks after a shorter idle period.
- **Stabilized GPU object storage and queue waits.** GPU objects no longer move when storage grows;
  constant-engine waits also handle counter wraparound and missing tasks safely.
- **Reduced memory-lock stalls.** Game arguments and results are accessed outside the runtime's
  region-table lock, avoiding a deadlock when a GPU-tracked page is touched during memory mapping.
- **Added `TLOU Game.exe`.** It starts the game using the launcher's last saved folders and settings.
- **Added Clear cache** to the launcher. It moves this game's shader and pipeline cache to the
  Windows Recycle Bin; the game recompiles shaders on the next run.
- Added a launcher option for game-thread priorities. The calibrated native clock remains enabled
  by default because the monotonic fallback makes this build run too fast.

## Update

Extract the zip over your previous folder, or into a new one. Your saves, settings and logs are in
its `analysis` folder: if you use a new folder, copy `analysis` across first. To keep your compiled
shaders, copy it with `analysis\tlou-user\cache` included.

## New install

1. Download **TLOU-Remastered-windows.zip** below and extract it to a folder with plenty of free space.
2. Open **TLOU Launcher.exe**.
3. Click **Folders** and choose **Game files**: the folder with `eboot.bin`. Update 1.11 is looked
   for beside it, in the folder of the same name ending in `-patch`.
4. Click **Play**. You can also open **TLOU Game.exe** to start with your saved launcher settings.

## Known issues

- **A separate Vulkan device-loss crash may still occur while entering new level geometry.** The
  water-and-pallet crash described above was reproduced as fixed; this broader level-transition
  failure has a separate report and its cause is not settled.
- **Shots pass through some parts of objects** with no effect, though they hit walls and most
  objects where the crosshair is. One firefly pendant, hanging from a tree in the courtyard after
  the quarantine zone, cannot be shot down for that reason.
- **Intel graphics cards do not work yet.** The game crashes at the start logos or the main menu,
  and the scene behind the menu is white.
- Soft shadows can look detached from objects, with a thin light outline around them and little
  darkening where they touch the ground, most visibly under vehicle wheels.
- NPCs sometimes move in jumps. It comes and goes between runs; a fixed 30 FPS limit had no jumps
  in the sessions tried, but this is not a general fix for unstable frame rates.
- Short pauses can occur the first time an area is played while its shaders compile. The async
  shader improvements above preserve draws but cannot remove the cost of compiling a new pipeline.
- DLSS and FSR 4 are not in this package: DLSS falls back to FSR 3.

When reporting a problem, attach `analysis\tlou\boot.log` (**Open log** in the launcher).
